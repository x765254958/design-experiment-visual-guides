# Example: L929 CCK-8 screening

Use this only as a structural example.

## Question

Does a particle formulation reduce L929 metabolic activity after a defined exposure, and what is the highest conservative candidate concentration for follow-up validation?

## Minimum logic

- normal cell control;
- particle-treated cell groups;
- no-cell reagent blank;
- no-cell material backgrounds at matching concentrations;
- optional blank-carrier groups from the same synthesis system;
- separate solvent/free-drug groups only when dose equivalence is defensible.

## Day structure

- D0: inspect, detach, count, prepare suspension, seed plate.
- D1: inspect attachment, prepare particle stock/working solutions, replace medium, treat.
- D2: photograph morphology, reduce particle interference consistently, add CCK-8, incubate, read OD450, save raw data.

## Visuals

- D0 layout: plate map with data wells, backgrounds, and edge filling.
- D0 operation: detachment, counting, suspension calculation, seeding.
- D1 operation: stock preparation, dilution table, medium replacement, treatment.
- D2 operation: imaging, medium replacement, reagent addition, incubation, reading, correction formula.

## Boundary

CCK-8 measures metabolic activity and may be affected by particles. Confirm a selected condition on a separate parallel plate using an orthogonal method when required.
